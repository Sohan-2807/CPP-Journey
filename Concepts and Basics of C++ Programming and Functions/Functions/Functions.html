Functions and Recursion in C++

Complete reference on default parameters, inline functions, function overloading rules, scope resolution, regular recursion, and class member function recursion.

1. Functions with Default Parameters/Arguments

Default arguments allow functions to be called without specifying all arguments. The compiler automatically substitutes the specified default value if omitted.

// Prototype: default values must be assigned right-to-left
double calcAmount(double principal, double rate = 5.0, int time = 2);

// Calls:
calcAmount(1000.0);             // rate = 5.0, time = 2
calcAmount(1000.0, 7.5);        // rate = 7.5, time = 2
calcAmount(1000.0, 7.5, 5);     // rate = 7.5, time = 5

2. Inline Functions

An inline function instructs the compiler to expand the function body at every point of call, eliminating the overhead of argument passing, register preservation, and stack frame allocation.

inline double simpleInterest(double p, double r, int t) {
    return (p * r * t) / 100.0;
}
⚠️ When Inlining is Ignored by Compiler

The compiler will reject the inline request if the function contains: loops (for, while), static variables, recursive calls, switch or goto statements, or when the function body is large.

3. Function Overloading & Scope Rules

Defining multiple functions with the same identifier in the same scope, differentiated by parameter count, types, or order.

Scope Rules in C++:

  • Local Scope (Block Scope): Variables and functions defined inside braces {} are invisible outside.
  • Class Scope: Members of a class are scoped to that class; accessed via obj.member or Class::member.
  • File / Global Scope: Identifiers declared outside all functions/classes, accessible throughout the translation unit.
  • Namespace Scope: Resolves naming conflicts across libraries (e.g. std::cout).
📌 Scope Resolution Operator `::`

The global scope resolution operator (::variable) accesses a hidden global variable when shadowed by a local variable with the exact same name.

4. Recursion: Functions & Member Functions

1. Standard Function Recursion
int fibonacci(int n) {
    if (n <= 0) return 0;
    if (n == 1) return 1;
    return fibonacci(n - 1) + fibonacci(n - 2);
}
2. Member Function Recursion

A member function calling itself recursively on the current instance:

class MathWizard {
public:
    int factorial(int n) {
        if (n <= 1) return 1;
        // Recursive call to member function:
        return n * factorial(n - 1);
    }
};

5. Parameter Passing Recap

Detailed in depth in CallBy.html:

  • Call by Value: Operates on local duplicates; caller variables remain unaltered.
  • Call by Address: Caller passes addresses using &; callee dereferences pointers with *.
  • Call by Reference: Parameters serve as aliases to the caller's actual variables.
