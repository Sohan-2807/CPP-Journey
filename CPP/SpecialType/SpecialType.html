2. Enumerations (Unscoped & Scoped)

// Unscoped Enum:
enum Day { MON = 1, TUE, WED, THU, FRI, SAT, SUN };

// Modern Scoped Enum (enum class) - Prevents name collisions and implicit int casts:
enum class StatusCode : int {
    Success = 200,
    NotFound = 404
};

StatusCode code = StatusCode::Success;
int numeric = static_cast<int>(code); // Explicit conversion

3. Unions in C++

A union is used when memory conservation is paramount and only one member is needed at any given instant.

union Value {
    int iVal;
    double dVal;
    char cVal;
};

int main() {
    Value v;
    v.iVal = 42;     // Active member is int
    v.dVal = 3.1415; // Overwrites iVal memory! Active member is now double
}

4. Features of Input/Output Streams

The C++ I/O system provides powerful stream features:

  • Type Safety: Automatically deduces data types during I/O operations (no format specifiers like %d or %s needed).
  • Extensibility: Can be extended to read and write user-defined classes by overloading << and >>.
  • Buffering: Utilizes stream buffers (streambuf) to optimize disk and console access speeds.
  • State Management: Maintains flags (good(), eof(), fail(), bad()) to track errors during transfer.

5. Manipulator Functions (``)

Manipulators modify stream formatting properties:

#include <iostream>
#include <iomanip>

int main() {
    // Width & Fill
    std::cout << std::setw(10) << std::setfill('*') << 50 << '\n'; // ********50

    // Precision & Fixed
    std::cout << std::fixed << std::setprecision(3) << 12.34567 << '\n'; // 12.346

    // Bases
    std::cout << std::hex << std::showbase << 255 << '\n'; // 0xff
}

6. Type Conversions (Basic Type ↔ Class Type)

A core Unit IV topic: converting between primitive data types and user-defined class objects.

1. Basic Type to Class Type

Accomplished via a Single-Argument Constructor in the destination class.

class Distance {
    int meters;
public:
    Distance() : meters(0) {}
    // Constructor enables Basic -> Class:
    Distance(int m) : meters(m) {}
};

Distance d = 500; // int converted to Distance!
2. Class Type to Basic Type

Accomplished via an Overloaded Casting Operator (operator type()).

class Distance {
    int meters;
public:
    Distance(int m) : meters(m) {}

    // Conversion Operator (No return type!):
    operator int() const {
        return meters;
    }
};

Distance d(250);
int m = d; // Distance converted to int!
