File Handling in C++: Complete Guide

Exhaustive reference on standard file streams (`fstream`), access modes, sequential & random access, binary object serialization, and error diagnostics.

1. Stream Hierarchy & Headers

In C++, file handling is implemented through the standard stream library in <fstream>. Files are treated as sequential streams of bytes.

  • std::ifstream: Input file stream (read-only operations). Derived from std::istream.
  • std::ofstream: Output file stream (write-only operations). Derived from std::ostream.
  • std::fstream: Simultaneous input and output stream (read and write). Derived from std::iostream.

2. Opening & Closing Files

A file stream can be opened using its constructor or via the explicit .open() method.

#include <fstream>
#include <iostream>

// Method 1: Constructor (Preferred - RAII ensures automatic closing)
std::ofstream outFile("data.txt");

// Method 2: Explicit open() and close()
std::ifstream inFile;
inFile.open("data.txt");

if (!inFile.is_open()) {
    std::cerr << "Error opening file!\n";
}

inFile.close(); // Closes file descriptor

3. File Open Modes

Modes are bitmask flags defined inside std::ios that can be combined using the bitwise OR operator (|).

Flag Description Default in
std::ios::in Open for input (reading). File must exist. ifstream
std::ios::out Open for output (writing). Overwrites existing content. ofstream
std::ios::app Append mode: Output is added at the end without truncating. -
std::ios::trunc Truncate mode: Discards all existing content if file exists. ofstream
std::ios::binary Binary mode: Reads/writes raw bytes without carriage-return translation. -
std::ios::ate "At the end": Seeks to the end of the file immediately upon opening. - 
// Example: Open in binary append mode for reading & writing
std::fstream file("log.bin", std::ios::in | std::ios::out | std::ios::app | std::ios::binary);

4. Writing to Files

std::ofstream out("students.txt");
if (out.is_open()) {
    out << "Alice 95\n";
    out << "Bob 88\n";
    out.put('A'); // Writes a single character
}

5. Reading from Files

1. Word by Word (`>>`)
std::string word;
while (inFile >> word) {
    std::cout << word << '\n';
}

Skips all whitespace (spaces, tabs, newlines).

2. Line by Line (`getline`)
std::string line;
while (std::getline(inFile, line)) {
    std::cout << line << '\n';
}

Preserves spaces; stops at newline character.

3. Character by Character
char ch;
while (inFile.get(ch)) {
    std::cout.put(ch);
}

Reads every single byte including whitespace.

6. Stream State & Error Checking

Stream objects maintain internal state bits to record operational status:

  • file.good(): Returns true if no error flags are set (stream is operational).
  • file.eof(): Returns true if End-Of-File has been encountered on a read attempt.
  • file.fail(): Returns true if a formatting or parsing error occurred (e.g. read letters into an int).
  • file.bad(): Returns true on unrecoverable hardware or buffer errors.
  • file.clear(): Resets error state bits back to good (crucial when rewinding streams!).

7. Random File Access (`seek` & `tell`)

C++ provides file position pointers that can be inspected and moved anywhere inside a file without sequential reading.

Function Stream Type Purpose
tellg() istream / ifstream Returns current get (read) pointer position in bytes.
tellp() ostream / ofstream Returns current put (write) pointer position in bytes.
seekg(offset, dir) istream Moves get pointer by offset relative to dir.
seekp(offset, dir) ostream Moves put pointer by offset relative to dir.

Seek Directions:

  • std::ios::beg: Beginning of the file.
  • std::ios::cur: Current position of the pointer.
  • std::ios::end: End of the file.
std::ifstream file("sample.txt");

// Get file size in bytes:
file.seekg(0, std::ios::end);
std::streampos fileSize = file.tellg();
file.seekg(0, std::ios::beg); // Rewind back to start

8. Binary File I/O: Structures & Classes (Syllabus Core)

Binary I/O transfers memory byte-for-byte using read() and write() via reinterpret_cast<char*>.

A. Structures and File Operations

struct StudentStruct {
    int rollNo;
    char name[50];
    double marks;
};

StudentStruct s1{101, "Alice", 95.5};

// Writing Structure to Binary File:
std::ofstream outFile("students.dat", std::ios::binary);
outFile.write(reinterpret_cast<const char*>(&s1), sizeof(StudentStruct));
outFile.close();

// Reading Structure from Binary File:
StudentStruct s2;
std::ifstream inFile("students.dat", std::ios::binary);
inFile.read(reinterpret_cast<char*>(&s2), sizeof(StudentStruct));
inFile.close();

B. Classes and File Operations

Encapsulating file read/write operations directly within class member functions:

class BankAccount {
private:
    int accNumber;
    char holder[40];
    double balance;

public:
    BankAccount(int a = 0, const char* h = "", double b = 0.0)
        : accNumber(a), balance(b) {
        strncpy(holder, h, 39);
        holder[39] = '\0';
    }

    void saveToFile(std::ofstream& out) {
        out.write(reinterpret_cast<const char*>(this), sizeof(*this));
    }

    void loadFromFile(std::ifstream& in) {
        in.read(reinterpret_cast<char*>(this), sizeof(*this));
    }
};
⚠️ Caution with Binary Serialization

Never binary dump objects containing raw pointers or virtual functions (VPTR)! Only Plain-Old-Data (POD) class members should be dumped directly.

9. Practical Case Studies

Counting Characters, Words, and Lines

int chars = 0, words = 0, lines = 0;
std::string line;
std::ifstream file("document.txt");

while (std::getline(file, line)) {
    lines++;
    chars += line.length() + 1; // +1 for newline
    
    std::stringstream ss(line);
    std::string word;
    while (ss >> word) words++;
}

File Duplication (Fast Binary Copy)

std::ifstream src("source.jpg", std::ios::binary);
std::ofstream dst("copy.jpg", std::ios::binary);
dst << src.rdbuf(); // Efficiently pipes raw stream buffer directly!

10. Pitfalls & Best Practices

🚫 Anti-Pattern: `while (!file.eof())`

In C++, the EOF flag is set only after an attempted read fails due to reaching the end. Using while (!file.eof()) causes the loop body to execute one extra time with stale or invalid data! Always test the read operation directly: while (file >> x) or while (getline(file, str)).
