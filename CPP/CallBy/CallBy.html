Parameter Passing & Reference Variables in C++

Complete reference covering Reference variables, Call by Value, Call by Address, Call by Reference, and a direct comparison between Pointers and References.

1. Reference Variables

A reference variable is an alias (an alternative name) for an existing variable. It shares the same memory address as the referent.

int original = 100;
int& ref = original; // ref is an alias to original

ref = 200; // Directly mutates original!
std::cout << original; // Outputs 200
std::cout << &original << " == " << &ref; // Exactly identical addresses!
⚠️ Three Key Reference Rules
  1. Must be initialized immediately upon declaration: int& r; // ERROR!
  2. Cannot be null.
  3. Cannot be reseated to refer to another variable after initialization.

2. Differences between Call by Value, Call by Address & Call by Reference

Characteristic Call by Value Call by Address (Pointer) Call by Reference
Parameter Passed A copy of actual data values. The memory address of actual data (&var). The variable itself as an alias (var).
Memory Allocation Allocates duplicate memory on callee stack frame. Allocates pointer memory (8 bytes) to store address. No separate storage allocated (handled as alias/pointer internally).
Caller Side Effects Callee changes do NOT affect caller. Callee changes affect caller via dereferencing (*ptr). Callee changes directly modify caller variables.
Can Accept NULL? No Yes (can pass nullptr) No (references cannot bind to null)
Syntax Simplicity Clean Cluttered with & and * Clean, intuitive syntax

3. Swap Function Case Studies

Call by Value (Fails to Swap)
void swapVal(int a, int b) {
    int t = a; a = b; b = t;
}
// swapVal(x, y);
// x and y are NOT swapped!
Call by Address (Swaps using Pointers)
void swapAddr(int* a, int* b) {
    int t = *a; *a = *b; *b = t;
}
// swapAddr(&x, &y);
// Swaps x and y!
Call by Reference (Idiomatic C++)
void swapRef(int& a, int& b) {
    int t = a; a = b; b = t;
}
// swapRef(x, y);
// Swaps x and y cleanly!

4. Differences Between Pointer and Reference Variables

A classic exam question directly from Unit II:

Feature Pointer Variable (int* ptr) Reference Variable (int& ref)
Definition A variable storing a memory address. An alias/alternative name for an existing variable.
Initialization Can be initialized anytime or left uninitialized (wild pointer). Must be initialized at the point of declaration.
Nullability Can be assigned nullptr (or NULL). Cannot be null.
Reassignment (Reseating) Can be reassigned to point to different addresses anytime. Cannot be reseated; binds permanently to its original referent.
Memory Address Has its own distinct memory address (&ptr != &val). Shares the exact same memory address as its referent (&ref == &val).
Dereferencing Requires dereference operator (*ptr) to access value. Accessed directly without any dereferencing syntax (ref).
Arithmetic Supports pointer arithmetic (ptr++, ptr + i). Does not support reference arithmetic (ref++ increments the value of the referent!).
Levels of Indirection Supports multiple levels of indirection (pointer to pointer: int**). Only one level of reference exists (cannot have reference to reference int&& in this context).

5. Exam & Best Practice Summary

  • Use pass by reference (or const T&) by default in C++ for objects and structures to eliminate copying overhead.
  • Use pass by address (pointers) when optionality is needed (can accept nullptr) or for dynamic polymorphism.
  • Use pass by value for primitive built-in types (int, float, char, bool).
