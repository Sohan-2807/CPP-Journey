Strings in C++: Complete Guide

Complete reference on C-style character arrays, dynamic `std::string` manipulation, input streams, reversal patterns, small string optimization, and zero-allocation string views.

1. C-Strings vs C++ `std::string`

C++ supports two fundamentally different ways to represent textual data:

Feature C-Style String (char[] / char*) C++ std::string (<string>)
Memory Model Fixed-size array ending in null byte \0 Dynamic heap buffer (with Small String Optimization)
Safety Unsafe (vulnerable to buffer overflows) Safe (manages capacity automatically)
Length Calculation $O(N)$ scanning with strlen $O(1)$ constant time via .size()
Copying & Concatenation Requires strcpy, strcat Intuitive operators: =, +, +=

2. C-Style Strings (``)

A C-style string is an array of characters terminated by the null character '\0' (ASCII value 0).

char greeting[] = "Hello"; // Array size is 6: 'H', 'e', 'l', 'l', 'o', '\0'

// Common C-string library functions (<cstring>):
size_t len = strlen(greeting);         // Length: 5 (ignores null byte)

char dest[20];
strcpy(dest, greeting);                // Copies greeting into dest
strcat(dest, " World");                // Concatenates " World"
int cmp = strcmp(greeting, dest);      // Lexicographical comparison
🚨 Buffer Overflow Hazard

If the source string in strcpy or strcat exceeds the capacity of the destination array, it writes past the allocated memory boundary, causing severe crashes or security vulnerabilities. Prefer modern std::string.

3. Modern `std::string` Core API (Syllabus Breakdown)

Included from <string>, std::string is a rich container class for text processing.

A. Defining & Assigning String Objects

std::string s1;                   // Empty string
std::string s2 = "Hello C++";     // Copy initialization
std::string s3(s2);               // Direct copy constructor
std::string s4(5, 'A');           // Fill constructor: "AAAAA"
std::string s5 = s2.substr(0, 5); // "Hello"
s1 = s2;                          // Assignment operator

B. Key Member Functions

  • s.size() / s.length(): Returns character count in $O(1)$ time.
  • s.capacity(): Returns currently allocated storage size before needing reallocation.
  • s.empty(): Returns true if string length is 0.
  • s.at(idx): Returns reference with bounds checking (throws std::out_of_range).
  • s.front() / s.back(): Returns first and last character.
  • s.c_str(): Returns null-terminated C-style const char*.
  • s.find(str, pos): Returns index of match, or std::string::npos if not found.
  • s.substr(pos, len): Generates and returns a new substring.

C. Modifiers of String Class

std::string str = "Base";

// 1. append / operator+=
str.append(" Ball");          // "Base Ball"
str += " Game";              // "Base Ball Game"

// 2. push_back / pop_back
str.push_back('!');           // Appends single char
str.pop_back();               // Removes last char

// 3. insert(pos, str)
str.insert(4, "ket");         // "Basketball Game"

// 4. erase(pos, len)
str.erase(10, 5);             // Removes " Game"

// 5. replace(pos, len, new_str)
str.replace(0, 6, "Foot");    // "Football"

// 6. swap(other)
std::string alt = "Tennis";
str.swap(alt);                // Fast O(1) buffer exchange

// 7. clear()
alt.clear();                  // Empties string

4. String Input Handling & Pitfalls

1. Single Word: `cin >> str`

Extracts characters until the first whitespace (space, tab, newline). Skips leading whitespace.

std::string word;
std::cin >> word;
2. Full Line: `getline(cin, str)`

Reads an entire line including spaces up to the newline character.

std::string fullLine;
std::getline(std::cin, fullLine);
⚠️ The Classic `cin >> num; getline(...)` Trap

When you read a number with cin >> age;, the trailing newline (\n) generated when pressing Enter remains in the input buffer. The immediate next call to std::getline() reads that empty newline and returns an empty string!

std::cin >> age;
std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n'); // Flush newline
std::getline(std::cin, name); // Now safely reads user input!

5. Algorithms & In-Place Reversal

Two-Pointers String Reversal

void reverseString(std::string& s) {
    int left = 0;
    int right = s.length() - 1;
    while (left < right) {
        std::swap(s[left], s[right]);
        left++;
        right--;
    }
}

Palindrome Check

bool isPalindrome(const std::string& s) {
    int left = 0, right = s.length() - 1;
    while (left < right) {
        if (s[left] != s[right]) return false;
        left++;
        right--;
    }
    return true;
}

6. Small String Optimization (SSO)

Modern C++ standard libraries implement SSO (Small String Optimization): small strings (typically up to 15–22 characters, depending on compiler and 64-bit architecture) are stored directly inside the string object on the stack without allocating heap memory! This gives extreme speed for short strings.

7. `std::string_view` (C++17, ``)

A non-owning, lightweight (pointer + length, 16 bytes) view over an existing string. Avoids expensive copying when passing substrings or string arguments to read-only functions:

#include <string_view>

void printPrefix(std::string_view sv) {
    // Zero dynamic memory allocation! Works with both std::string and "literal"
    std::cout << sv.substr(0, 4) << '\n';
}
